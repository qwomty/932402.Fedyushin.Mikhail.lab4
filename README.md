# Лабораторная работа №4

## Особенности проекта

* **Запуск по событию:** скрипт анализа громкости привязан к кнопке «Запустить анализ громкости» в шапке сайта.
* **Интерактивный ввод и вывод:** взаимодействие с пользователем реализовано через окна `prompt` (запрос имени с обработкой отмены и пустого ввода) и `alert` (приветствие и итоговая сводка), а подробная аналитика выводится в `console.log`.
* **Пользовательские функции:** логика разделена на отдельные функции для подсчёта суммы массива (`calculateSum`), поиска максимума (`findMax`) и фильтрации громких треков свыше 90 дБ (`filterLoudTracks`).
* **Циклы и фильтрация данных:** с помощью цикла `for` и условных конструкций отбираются тихие треки (≤ 75 дБ), определяется их количество и вычисляется средняя громкость.
* **Контроль пиковой нагрузки:** реализована проверка максимальной громкости — при достижении порога ≥ 105 дБ в консоль выводится предупреждение о защите слуха.

* ## Пример работы скрипта
Исходный массив: `[70, 74, 86, 88, 96, 108]`

**Вывод в диалоговых окнах (alert):**
1. `Привет, qwomty! Запускаем анализ громкости треков.`
2. `Средняя громкость – 87 дБ, 2 треков – громкие`

**Вывод в консоль (console.log):**
- Исходный массив громкости треков (дБ): `[70, 74, 86, 88, 96, 108]`
- Громкие треки (> 90 дБ): `[96, 108]`
- Количество тихих треков (≤ 75 дБ): `2`
- Средняя громкость тихих треков: `72 дБ`
- Максимальная громкость: `108 дБ`
- `Такая громкость может повредить слух – используйте наушники с ограничением`
